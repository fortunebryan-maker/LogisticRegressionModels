# Logistic Regression Projects 

A collection of classification projects
built using Logistic Regression as part
of my self-taught Machine Learning journey.

## Projects

### 1. Titanic Survival Predictor 
Predicts whether a passenger survived
the Titanic disaster based on age,
sex, class and other features.
- Accuracy: 80%
- Key challenge: Encoding + missing values

### 2. Bank Marketing Predictor 
Predicts whether a bank customer will
subscribe to a term deposit based on
demographic and campaign data.
- Accuracy: 91.16%
- Key challenge: 47 features after encoding,
  unknown value handling

### 3. Diabetes Predictor 
Predicts whether a patient has diabetes
based on medical measurements.
- Accuracy: 70.78%
- Key challenge: Hidden zeros treated
  as missing values

### 4. Breast Cancer Classifier 
Classifies tumors as malignant or benign
using 30 cell nucleus measurements.
- Accuracy: 98.25%
- Key challenge: 30 features,
  identifying most important predictors

## Tools Used
Python, Pandas, NumPy, Scikit-learn,
Matplotlib, Seaborn, Jupyter Notebook

## Key Learnings
- Encoding categorical variables
- Handling missing and impossible values
- StandardScaler improves convergence
- Class imbalance affects recall scores
- Feature importance using coefficients
